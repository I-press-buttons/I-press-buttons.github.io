# Working in this repo

## "YOLO" means ship it

When I say **YOLO**, take the current branch all the way to `main` without
asking first:

1. Commit and push any remaining work on the branch.
2. Open a pull request into `main` if the branch does not already have one.
3. Merge the pull request into `main`.
4. Delete the branch on GitHub.

Then tell me it is merged and give me the PR link. If a step cannot be done
(a merge conflict, a failed check, missing permission), stop there and tell me
what blocked it instead of working round it.
